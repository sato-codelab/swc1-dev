# 価値判断AIマッチング（仮称）— 10問MVP

## 起動方法

1. ZIPを展開します。
2. `files_week4/index.html` をブラウザで開きます。
3. 左右の選択肢から回答し、各問の結果画面で「次の問題へ」を押します。
4. Q10まで回答すると、3つのAIモックとの10問全体の一致率が表示されます。

外部ライブラリやバックエンドは使用していません。回答はブラウザの `localStorage` に保存されます。

## 画面とオプション

- 起動時にスタート画面を表示します（途中まで回答済みの場合は「続きから再開」を選べます）。
- 右上の「オプション」で「演出をスキップ」を切り替えられます（設定は別キーで保存され、診断のやり直しでは消えません）。演出中は「演出をスキップ」ボタンでも飛ばせます。
- 全問回答後は診断終了画面で、AI別の一致率と最も近いAIを表示します。

## 問題セット

Q01 5人を救うために進路を変えるか
Q02 身近な1人か、見知らぬ3人か
Q03 平等に配るか、必要性を考慮するか
Q04 確実な1人か、助かる可能性に賭けて2人か
Q05 未確認の警報をすぐ共有するか
Q06 プライバシーを守るか、周囲の安全を優先するか
Q07 仲間を守るか、ミスを明らかにするか
Q08 経験を優先するか、協力しやすさを優先するか
Q09 全員に少しずつか、必要な人へ十分にか
Q10 目の前の支援か、将来の被害を防ぐ投資か

## テスト

Node.jsが利用できる環境で、プロジェクトフォルダ内から以下を実行します。

```sh
node tests/test-app-core.js
```

回答は動作確認用のモックデータであり、実際に生成AIへ問い合わせた回答ではありません。一致率は今回の問題セット内での回答パターンの類似度であり、倫理的な優劣を表すものではありません。
